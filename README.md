# B站API爬虫 - 完整版本

一个功能完整的B站API爬虫程序，支持视频信息获取、评论、弹幕、用户信息、搜索、热门视频、排行榜以及视频下载等功能。

## 🚀 功能特性

- ✅ 视频信息获取（标题、作者、播放量、点赞数等）
- ✅ 视频评论获取（支持分页）
- ✅ 视频弹幕获取
- ✅ 用户信息获取（基本信息、粉丝数、关注数等）
- ✅ 用户视频列表获取
- ✅ 用户粉丝/关注列表获取
- ✅ 视频搜索功能
- ✅ 热门视频获取
- ✅ 排行榜视频获取
- ✅ **番剧信息获取和下载**（新增功能）
- ✅ 视频下载功能（支持多种质量）
- ✅ 数据保存为JSON文件
- ✅ 支持多种URL格式（BV号、AV号、短链接、番剧URL）

## 📋 使用说明

### 环境要求

- Python 3.6+
- 依赖包：`requests`

### 安装依赖

```bash
pip install requests
```

### 运行程序

```bash
python bilibili_api_complete.py
```

### 功能菜单

程序启动后会显示功能菜单：

1. 获取视频详细信息
2. 获取视频评论
3. 获取视频弹幕
4. 获取用户信息
5. 获取用户视频
6. 获取用户粉丝
7. 获取用户关注
8. 搜索视频
9. 获取热门视频
10. 获取排行榜
11. 下载视频（普通视频）
12. 下载番剧视频
13. 获取番剧信息
0. 退出

## 🔧 技术特点

- 使用B站官方API，完全合规
- 支持番剧URL处理（ep/ss格式）
- 自动识别和转换多种URL格式
- 详细的错误处理和日志输出
- 数据格式化显示和保存
- 支持视频下载（DASH格式）
